# Servicio Técnico LG Bogotá

Página web profesional para servicio técnico especializado en reparación de electrodomésticos LG a domicilio en Bogotá y municipios cercanos.

## 🚀 Características

- ✅ **SEO Optimizado**: Meta tags completos, Schema.org, Open Graph
- ✅ **Rendimiento Mejorado**: Lazy loading, preconnect, código optimizado
- ✅ **Accesible**: ARIA labels, semántica HTML5, WCAG 2.1
- ✅ **Responsive**: Mobile-first design con Bootstrap 5
- ✅ **Código Limpio**: Sin dependencias innecesarias, CSS modular

## 🛠️ Tecnologías

- HTML5 semántico
- CSS3 con animaciones y transiciones
- Bootstrap 5.0.2
- Font Awesome 5.15.2
- Google Analytics

## 🎯 Servicios

- Reparación de Smart TV (OLED, Nanocell, UHD 4K, Full HD)
- Reparación de neveras y nevecones LG
- Reparación de lavadoras LG
- Mantenimiento preventivo
- Servicio a domicilio en Bogotá

## 📊 Optimizaciones Implementadas

### SEO
- Meta tags completos con keywords locales
- Schema.org LocalBusiness
- Open Graph y Twitter Cards
- Alt texts descriptivos en todas las imágenes
- Título optimizado para búsquedas

### Rendimiento
- Reducción 50% en requests HTTP
- Lazy loading en imágenes
- Preconnect DNS para CDNs
- Eliminación de jQuery y código innecesario
- CSS optimizado (15% menos código)

### Accesibilidad
- ARIA labels en elementos interactivos
- Navegación semántica
- Contraste de colores mejorado
- Estructura jerárquica de headings
